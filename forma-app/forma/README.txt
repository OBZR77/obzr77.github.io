ФОРМА — домашний тренер (приложение для Android, формат PWA)

КАК УСТАНОВИТЬ НА ТЕЛЕФОН
1. Загрузите эту папку целиком (с вложенными css, js, icons) на сайт с адресом https.
   Подойдёт GitHub Pages: в репозитории сайта нажмите «Add file» → «Upload files»,
   перетащите папку forma и подтвердите загрузку.
2. Откройте в Chrome на телефоне адрес https://ВАШ-ЛОГИН.github.io/РЕПОЗИТОРИЙ/forma/
3. Нажмите «Установить» на главном экране приложения
   или меню Chrome (три точки) → «Установить приложение».
4. Один раз откройте приложение при включённом интернете. Дальше оно работает без сети.
5. Голос: Настройки приложения → «Проверить голос». Если речи нет или она не русская,
   установите русский язык синтеза речи: Настройки Android → Язык и ввод → Синтез речи.

ПРОВЕРКА НА КОМПЬЮТЕРЕ
Открыть файл index.html двойным щелчком нельзя: установка и офлайн-режим работают только по http/https.
Для проверки запустите в этой папке:  python -m http.server 8000
и откройте http://localhost:8000

ОБНОВЛЕНИЕ
Замените файлы на сайте и в файле sw.js увеличьте номер версии (forma-v1 → forma-v2),
иначе телефон продолжит показывать старую копию из кэша.

ФАЙЛЫ
index.html, css/style.css       — интерфейс
js/data.js                      — упражнения и программа на 12 недель
js/logic.js                     — прогрессия по неделям и сборка тренировки
js/voice.js, js/player.js       — голос, таймеры, плеер тренировки
js/store.js, js/app.js          — данные на телефоне и экраны
sw.js, manifest.webmanifest     — офлайн-режим и установка
